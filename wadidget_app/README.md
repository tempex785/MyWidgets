# Wadidget (واديجتس)

تطبيق Flutter مطابق لتصميم الصور المرفقة:
- شاشة Splash
- Onboarding (4 خطوات): اللغة - شكل الويدجتس - المظهر
- شاشة الصلاحيات (تفعيل الموقع / الإشعارات / التشغيل في الخلفية)
- الشاشة الرئيسية: ساعة رقمية + أوقات الصلاة + الطقس + نتائج مباريات + سلايدر إعلاني

## التشغيل
flutter pub get
flutter run
