# ودجتي 2.0 — تطبيق ويدجتات كامل (Wadiget-like)

تطبيق أندرويد Kotlin بنفس فكرة تطبيق Wadiget: ويدجتات للشاشة الرئيسية + شاشات كاملة.

## الشاشات (10)
1. **جولة التعريف (Onboarding)** — 5 صفحات: ترحيب، الموقع، البطارية، الإشعارات، البداية
2. **الرئيسية — استكشاف** — بطاقات كل الويدجتات مع زر تثبيت
3. **الاستوديو** — لون التمييز (6 ألوان)، شفافية الخلفية، تحديث فوري
4. **الإعدادات** — الموقع، مذهب العصر، الاشتراك، تواصل، عن التطبيق، مشاركة
5. **الاشتراكات** — 3 خطط + استرجاع + إلغاء (وضع تجريبي بدون دفع حقيقي)
6. **تواصل معنا** — نموذج يرسل بالبريد
7. **عن التطبيق** — الإصدار وتقييم ومشاركة
8. **المهام والعادات** — إضافة/إنجاز/حذف
9. **فرقي ودورياتي** — اختيار حتى 5 فرق
10. **(شاشة ضمنية)** إعدادات ويندوز تفتح من الويدجتات نفسها

## الويدجتات (6)
- الساعة والتاريخ (ميلادي + هجري)
- مواقيت الصلاة (الصلاة القادمة + الكل، مدينة ومذهب من الإعدادات)
- اقتباسات وأذكار (اضغط للتنقل)
- التسبيح (عدّاد + جولات 33)
- المهام (اضغط لفتح الإدارة)
- مباريات فرقك (يتطلب ربط API رياضي قبل النشر)

## التشغيل
1. افتح المجلد في Android Studio → Gradle Sync → Run ▶
2. ثبّت أي ويدجت من التطبيق أو من قائمة اللانشر
3. كل التخصيصات تنعكس على الويدجتات فورًا

## ملاحظات صريحة
- الاشتراك واجهة تجريبية — للنشر الحقيقي اربط Google Play Billing
- ويدجت المباريات يحتاج خدمة بيانات رياضية (مدفوعة عادةً)
- التحديث التلقائي: كل 30 دقيقة (حد أندرويد الأدنى)
